# Streamlit Smoke-Test Checklist

Use this checklist before a client-facing demo or after small stabilization edits.

- Executive View loads.
- Zone Explorer loads.
- Recommendation Engine loads.
- Data Intake loads.
- Data Validation loads.
- KPI Assurance loads if present.
- Scenario Settings loads.
- Export page loads.
- No page shows a raw traceback.
- No page has visible mojibake or encoding artifacts.
- Public app URL reaches the rendered app, not just a loading spinner.
- Export buttons are visible on the Export page.
- Recommendation Engine still shows provisional treatment, illustrative support treatment, reason codes, hard gates, next action, validator/owner, and human review status.
